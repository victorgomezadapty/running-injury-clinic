Suggested attribution for the derived pilot

Adapted from Ferber R, Brett K, Fukuchi R, Hettinga B, Osis S, Running Injury Clinic Kinematic Dataset, version 1 (2024), https://doi.org/10.25452/figshare.plus.24255795.v1, licensed under CC BY 4.0. This project selected 30 participants for a technical pilot, removed source identifiers and selected source-provided bilateral discrete values. No new joint-angle reconstruction or independent event/cycle validation is claimed. Changes: selection, column renaming, project row IDs and packaging.

Privacy and redistribution

Removing direct identifiers does not guarantee anonymity. Exact biomechanical values may be linkable to public upstream files, particularly in a 30-row selected pilot. The Kaggle release contains no source IDs, filenames, injury-location labels or raw trajectories. Opaque row labels are not a guarantee of anonymity. Reusers should preserve attribution, respect the source consent/ethics context and avoid attempts at participant identification or unsupported clinical inference. The full 22.75 GB source archive is not redistributed here.
